1. What is the difference between invoking and creating a function?

    2. Creating a function means writing what it should do. Invoking a function means calling it to run the code.

  2. Explain the syntax regarding semicolons and code blocks.

    Semicolons usually go at the end of statements. Curly brackets { } group code into a block. A normal function declaration does not need a semicolon after its closing bracket.

  3. What happens when we try to store values from a function when it does not return any?

    The variable gets undefined because the function does not return a value. Printing something is not the same as returning it.

  4. How do we separate parameters from each other when creating a function?

    We use commas between parameters. For example: function add(first, second).

  5. Explain how parameter names are related during the invocation and creation of a function.

    Parameters are names used inside the function. When we call it, the values go into these parameters in the same order. Names of variables outside the function can be different.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    If we do not pass a value, the parameter gets undefined. If the parameter has a default value, it uses that instead.

  7. Explain what happens when we use recursive functions.

    A recursive function calls itself to solve a smaller part of the problem. It needs a stopping condition. Without it, the calls can continue until an error happens.
